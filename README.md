# LAIORA BOULANGERIE — Landing Page / Biolink

Landing page resmi **Laiora Boulangerie** yang dirancang sebagai bio link mobile-first untuk memudahkan customer melihat identitas brand, menghubungi WhatsApp, dan mengakses kanal penjualan serta media sosial Laiora dalam satu halaman.

> **Cakes & sweet treats for every occasion**  
> Freshly baked untuk dinikmati sendiri, gift, hampers, ulang tahun, acara keluarga, dan berbagai momen spesial.

---

## Tentang Laiora Boulangerie

**Laiora Boulangerie** adalah brand bakery yang berlokasi di **Kalideres, Jakarta Barat**.

Pilihan sajian Laiora mencakup antara lain:

- Brownies
- Bolu jadul
- Birthday cake
- Gift & hampers
- Sweet treats untuk berbagai acara spesial

Landing page ini dibuat dengan pendekatan visual **semi-vintage bakery** yang clean, refined, dan berkarakter, menggunakan perpaduan warna powder blue, ivory/white, royal blue, dan aksen gold.

---

## Tujuan Landing Page

Landing page ini berfungsi sebagai pusat akses singkat dari Instagram, TikTok, dan kanal digital Laiora.

Customer dapat langsung:

- Menghubungi Laiora melalui WhatsApp
- Melihat produk di Shopee
- Mengunjungi TikTok Laiora
- Mengunjungi Instagram Laiora
- Melihat area pengiriman
- Mengenal karakter visual dan positioning brand Laiora

## Konsep Visual

Desain landing page mengikuti identitas Laiora dengan karakter:

- Semi-vintage bakery
- Soft luxury
- Classic French bakery mood
- Clean dan mobile-friendly
- Powder blue / soft royal blue
- Ivory / bright white
- Muted gold accent
- Vintage engraving illustration
- Fokus visual pada logo **LAIORA BOULANGERIE**

## Deployment

Landing page dapat di-deploy sebagai static site menggunakan layanan seperti:

- Netlify
- GitHub Pages
- Cloudflare Pages
- Vercel

Untuk deployment sederhana, pastikan file utama bernama:

```text
index.html
```

lalu upload seluruh file project ke hosting static yang digunakan.
